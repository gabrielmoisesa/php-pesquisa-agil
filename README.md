## 📚 Conteúdo da Pesquisa

### O que é o PHP?
PHP (PHP: Hypertext Preprocessor) é uma linguagem de programação interpretada, executada no lado do servidor, voltada ao desenvolvimento web. Suporta múltiplos paradigmas: imperativo, funcional, orientado a objetos, procedural e reflexivo.

### História & Criador
Criada por **Rasmus Lerdorf** em **1994**, originalmente como um conjunto de scripts em C para monitorar visitas em sua página pessoal. O nome inicial era *Personal Home Page Tools*. Com o crescimento da comunidade, evoluiu para um acrônimo recursivo: **PHP: Hypertext Preprocessor**.

### Histórico de Versionamento

| Versão | Ano |
|--------|:---:|
| CGI / PHP 1 | 1994 |
| PHP/FI | 1995 |
| PHP 3/4 | 1997 |
| PHP 5 | 2004 |
| PHP 6 | 2005 *(não lançado)* |
| PHP 7 | 2015 |
| PHP 8 | 2020 |
| **PHP 8.5** *(atual)* | **2025** |

### Versão Atual: PHP 8.5
Lançado em **20 de novembro de 2025**, com suporte até **31 de dezembro de 2029**. Principais novidades:
- Extensão URI nativa
- Operador de tubulação (*pipe operator*)
- Closures e funções chamáveis de primeira classe em expressões constantes
- Funções `array_first()` e `array_last()`

### Principais Características

| Característica | Descrição |
|----------------|-----------|
| **Multi-paradigma** | Suporta POO, procedural e funcional no mesmo projeto |
| **Alta Integração** | Conecta-se nativamente com MySQL, PostgreSQL, Oracle, MongoDB |
| **Ecossistema Rico** | Frameworks como Laravel, Symfony, CodeIgniter |

### Vantagens

- **Open Source** — gratuito, sem custos de licenciamento
- **Comunidade Gigante** — documentação, fóruns e bibliotecas amplamente disponíveis
- **Flexibilidade** — compatível com Apache, Nginx e principais bancos de dados
- **Alto Desempenho** — PHP 8.x introduz JIT (Just-In-Time Compiler)
- **Segurança Nativa** — proteção integrada contra SQL Injection, XSS e CSRF
- **Escalabilidade Cloud** — compatível com AWS, Azure e Google Cloud via containers Docker

### Desvantagens

- **Estigma do Legado** — preconceito histórico associado a más práticas das versões 4 e 5
- **Sintaxe Inconsistente** — nomenclatura e ordem de parâmetros irregulares em funções nativas (ex: `strlen` vs `str_replace`)
- **Erros Silenciosos** — tipagem fraca padrão pode mascarar bugs se `declare(strict_types=1)` não for utilizado

### Áreas de Aplicação
PHP domina o desenvolvimento back-end web, com forte presença em:
- **CMS** — WordPress, Drupal, Joomla
- **E-commerce** — Magento, WooCommerce
- **Frameworks** — Laravel, Symfony, CodeIgniter
- **Sistemas corporativos, APIs e portais de conteúdo**

### Empresas que Utilizam

| Empresa | Tecnologia PHP |
|---------|---------------|
| Nike / Coca-Cola / Ford | Magento (e-commerce) |
| The Economist / WhiteHouse.gov | Drupal (portal de conteúdo) |
| Diversas plataformas SaaS | Laravel |

### Curiosidades
- Funções PHP são **objetos de primeira classe** — podem ser passadas como argumentos para outras funções.
- `array_map()` recebe o callback no **primeiro** parâmetro; `array_filter()` recebe no **segundo** — uma inconsistência histórica proposital.
- O prefixo `b` em strings (ex: `b"texto"`) é um token de compatibilidade da versão 6 nunca lançada, que prometia suporte total a Unicode. Representa *binary string*, cujas funções operam em nível de byte.
